# Folder Skin Tool for Mac

独立的 macOS 版本，不依赖旁边的 Windows 项目。支持 Intel 和 Apple 芯片 Mac 所用的 Python 环境；实际 Finder 换肤需要 macOS 和 PyObjC。

## 第一次启动

1. 把整个 `folder_skin_tool_mac` 文件夹复制到 Mac 的个人目录，例如「文稿」。不要放进系统目录或只读磁盘。
2. 准备 **Python 3.10 或更新版本，且包含 Tkinter**。可以使用 [Python 官网的 macOS 安装包](https://www.python.org/downloads/macos/)。Anaconda 用户也可以指定自己的 Python。
3. 在终端输入 `cd `（注意最后有空格），把工具文件夹拖进终端，按回车。
4. 输入 `bash Setup.command`。首次需要联网安装 Pillow 和 PyObjC，并在本目录创建 `.venv`，不改系统 Python。
5. 安装完成后双击 `Start.command`，或在终端运行 `bash Start.command`。

如果从 Windows 复制后不能双击 `.command`，先使用上述 `bash` 启动方式。安装成功会设置启动文件的执行权限。

指定已有 Python 的示例：

```bash
FOLDER_SKIN_PYTHON="/你的Python环境/bin/python3" bash Setup.command
```

如果提示找不到 `_tkinter`，请换用包含 Tkinter 的 Python，再运行安装步骤。如果安装失败，先查看终端最后的错误，不要用 sudo 启动整个工具。

## 功能对照

| 功能 | Mac 版支持情况 |
| --- | --- |
| 角色＋文件夹、仅角色、仅文件夹 PNG | 支持 |
| 文件夹颜色、自定义皮肤、左右和上下移动、缩放 | 支持 |
| 前后遮挡、倾斜开口、接触阴影 | 支持 |
| 去留白、成品放大 100%–160% | 支持，放大会产生裁切 |
| 手动保存 PNG＋ICO、PNG 直接转 ICO | 支持，ICO 保留六种尺寸 |
| 保存 Mac 原生 ICNS、PNG 直接转 ICNS | 支持 |
| 单个文件夹换肤、恢复、恢复全部 | 使用 Finder 原生接口 |
| 导入 PNG／ICO／ICNS 后直接应用 | 支持 |
| 批量换肤 | 选定目录内现有的直接子文件夹，不递归、不跟踪新建目录 |
| 修改全系统默认文件夹图标 | **未提供**；不修改受保护的系统资源，不关闭 SIP |

## 如何制作图标

1. 在左上方选「制作模式」。
2. 选择对应 PNG。仅角色不需要文件夹图片；仅文件夹不需要角色图片。组合模式可以不选文件夹 PNG，使用内置纯色模板。
3. 调整角色位置、大小；文件夹的位置在右侧「皮肤位置」。
4. 在「立体遮挡」里显示辅助线，调整左右开口端点，让角色位于后片和前片之间。辅助线不保存。
5. 「成品大小」控制最终图案大小，超过 100% 可能裁掉边缘。
6. 「手动保存 PNG + ICO」保存一组文件；Mac 图标可在「导入 / Mac」页点击「手动保存当前预览为 ICNS」。

需要透明背景 PNG；白底、绘制进去的棋盘格不会自动去除。绒面材质、厚度等依赖素材，工具不生成三维模型。单图模式不会添加文件夹或遮挡。

「匹配 Mac 默认文件夹大小」从本机读取默认文件夹轮廓，调整组合模式中文件夹的比例；单图模式请直接用大小控件。它不改变 Finder 自身的图标显示尺寸。界面内容较多时可使用右侧滚动条。

## 单张图片直接转换

- **PNG 转 ICO**：在主界面选择 PNG，再选择 ICO 保存位置。只保存 ICO，保留原图完整内容和比例，透明补边。
- **PNG 直接转 ICNS**：在「导入 / Mac」页选择 PNG，再手动保存为 ICNS。只保存 ICNS。

不需要目标文件夹，不依赖当前构图，不覆盖源 PNG。应用皮肤时不会自动在输出目录保存成品；系统保存必要的文件夹图标元数据，工具保存恢复备份。

## 给 Mac 文件夹换肤

制作好预览后，选择自己的普通文件夹，点击「应用皮肤」。

已有 ICO、ICNS 或 PNG 可以直接在「导入 / Mac」页导入，再点击「应用导入图标到所选文件夹」。不用重新制作角色图片。

工具调用 Apple 的 `NSWorkspace.setIcon`，不使用 Windows 的 `desktop.ini` 或注册表。不需要管理员权限，但目标必须可写。第一次访问桌面、文稿或下载目录时，macOS 可能询问文件访问权限；请按实际需要授权。没有权限时可先在个人目录的新建测试文件夹上试用。

变化通常由 Finder 自行显示。若未立即更新，先离开并重新打开该目录。工具不自动重启 Finder、不注销、不修改系统图标缓存。若小图标不清晰，可用 Finder「显示查看选项」调整图标大小。

## 批量应用，以及全局默认限制

选择一个包含多个文件夹的目录，导入图标后点击「批量应用到所选目录的直接子文件夹」。确认框会显示数量和部分名称。

只处理这一层已有的非隐藏普通文件夹，跳过链接和应用包；不改变父目录、不深入孙级目录、不自动处理以后新建的文件夹。每个成功的目录都有独立备份，失败项会显示原因。

macOS 没有与 Windows `Shell Icons` 注册表覆盖对应的受支持全局接口。系统资源受保护，不能把批量设置宣传为“系统默认已替换”。本工具不会关闭 SIP 或修改系统卷；如果你要求未来新建的所有文件夹也自动使用同一图标，当前版本不能做到。

## 恢复与备份

- 「恢复所选文件夹」还原换肤前的图标；原来没有自定义图标时，移除本次自定义图标。
- 「恢复全部已换肤文件夹」只处理本工具记录的目录，不扫描其他文件夹。
- 已有自定义图标会按原来的显示图像备份、恢复；不承诺底层资源文件逐字节相同。
- 如果其他软件修改了图标，停止自动恢复并保留备份。
- 文件夹移动、重命名后，请移回原路径再恢复。路径被其他目录占用时拒绝恢复。

备份位于：

```text
~/Library/Application Support/FolderSkinToolMac/skin_registry.json
```

在 Finder 按 **Command + Shift + G**，粘贴目录部分即可打开。恢复完成前请保留该目录。不要手动删除 Finder 的隐藏 `Icon` 资源文件。

如果程序在应用或恢复过程中异常退出，会保留待处理记录。不能确认当前图标是否仍属于本工具时会停止自动覆盖。记录中 `original` 为换肤前图标 TIFF 的 Base64；需要人工恢复时，可先复制备份，再将对应字段解码保存为 `.tiff`，在「预览」打开并复制图像，粘贴到文件夹「显示简介」左上角的图标。`original` 为 null 表示原来没有自定义图标，可在简介中选中图标后按 Delete 恢复默认。人工处理后请保留记录并请熟悉程序的人清理对应条目，不要直接删除所有备份。

## 已做验证与限制

本版本在 Windows 上制作。图片处理、ICO／ICNS 编解码、界面启动和使用模拟 Finder 的恢复测试可以在开发机验证；**尚未在真实 macOS Finder 中端到端验证**。首次请用新建测试文件夹确认应用和恢复，再用于重要目录。

运行通用测试：

```bash
.venv/bin/python -m unittest -v
```

在 Mac 上额外验证真实 Finder 接口（只操作测试创建的临时目录）：

```bash
FOLDER_SKIN_MAC_TEST=1 .venv/bin/python -m unittest -v
```
