# Folder Skin · 文件夹换肤

双击 **Start.cmd** 启动。使用现有的 `E:\Anaconda\envs\comp5310\python.exe`，无需安装新环境。

1. 选择本地普通文件夹。
2. 选择透明 PNG（或先体验附带的小幽灵）。
3. 可在角色选项下方选择「文件夹皮肤 PNG」，替换整个纯色文件夹外观。留空则继续使用纯色文件夹。
4. 调整角色大小和上下位置；右侧可独立调整皮肤 PNG 的大小和上下位置。颜色仅影响纯色模式。
5. 点击「应用皮肤」直接换肤，不会自动导出 PNG/ICO 副本。需要保存成品时，点击「手动保存 PNG + ICO」，选择位置和文件名；取消对话框不会保存。
6. 随时点击「恢复所选文件夹」或「恢复全部已换肤文件夹」。

图标包含 16、32、48、64、128、256 像素六种尺寸。角色位于文件夹背面与正面之间，背景透明。手动保存的默认位置为 `generated_icons`，可以另选目录。原图只读取，不修改。应用皮肤时只在目标文件夹写入 Windows 显示所需的隐藏 ICO 和配置，不在输出目录保存 PNG 或 ICO 副本。已有导出文件不会自动删除。

自定义皮肤建议使用透明背景的空文件夹 PNG，可放在 `assets` 或任意本地目录。程序裁去透明边距并保持比例，将皮肤放在图标下方；不会残留默认文件夹。PNG 原有颜色和透明区域会保留，白底或自带棋盘格的图片不会自动去底。点击「清除皮肤，使用纯色文件夹」可切回原样式。

## 让角色进入文件夹

右侧「立体遮挡」默认启用「角色进入文件夹」。选择自定义皮肤后：

1. 勾选「显示开口辅助线」。
2. 调整「开口左端高度」和「开口右端高度」，使蓝色虚线贴近文件夹前片的上边缘。滑块越往右，该端越靠下。
3. 线以上的皮肤作为后片、线以下作为前片；角色放在两者之间。回到角色位置滑块，调整露出的部分。
4. 调整「开口阴影强度」，为前片边缘附近的角色加上接触阴影。
5. 导出或应用，辅助线不会出现在成品中。皮肤大小和位置滑块移到了「皮肤位置」页。

取消「角色进入文件夹」即可恢复整张皮肤遮挡角色的旧模式。纯色模式本身已有前后片，新增阴影同样生效；开口端点滑块仅作用于自定义皮肤 PNG。

这是可调的二维分层遮挡，不是自动 3D 建模或材质生成。单张 PNG 使用直线分隔前后片，支持倾斜开口；复杂曲线和不规则前片无法精确自动分割。素材自身的透视、厚度与光照仍决定最终效果。

## 恢复与备份

- 使用 Windows 原生 `desktop.ini`、隐藏图标和文件夹只读属性；不修改注册表、系统 DLL，不重启资源管理器。
- `data/skin_registry.json` 保存换肤前的 desktop.ini 原始字节和属性，**有尚未恢复的文件夹时，请保留整个工具目录及 data 文件夹**。
- 原本没有自定义图标的文件夹恢复为默认图标；原本有自定义设置的文件夹恢复为之前的设置。
- 重复应用时先恢复上一次设置，再应用新的皮肤。
- 恢复全部只处理本工具记录的文件夹。不会扫描、删除其他用户文件。
- 如果其他软件修改了 desktop.ini 或本工具图标，会停止恢复该文件夹并保留备份，避免覆盖新更改。
- 操作中断时保留待恢复记录；重新打开工具并执行恢复。若配置文件写入中途发生部分写入，可能需要依据备份人工处理，工具不会猜测并覆盖。
- 换肤期间请不要移动或重命名目标文件夹。记录按原路径保存，移动后请先移回原位置再恢复。
- 不支持网络共享、磁盘根目录、目录链接、联接点和云端占位目录。
- 图标显示受 Windows 缓存和当前图标大小影响；没有马上更新时按 F5，必要时重新登录。程序不会主动清理系统缓存。

此工具是静态文件夹图标，不含动画。未下载任何第三方角色素材。附带小幽灵为程序绘制的示例，不是对缺失参考图的复刻。

## 左右移动与默认尺寸

默认开启「放大成品，去除四周留白」：完成合成后按透明度大于 16/255 的可见主体计算边界，忽略外围几乎不可见的残影，将整体等比例放大到画布约 98% 的范围。最外侧极淡的阴影可能被裁去。右侧「成品大小」提供 100%–160% 的进一步放大，以及「放大到 120%」「恢复完整显示」按钮；超过 100% 会裁切超出画布的部分，请根据预览调整。预览、PNG 和各尺寸 ICO 使用相同结果，开口辅助线也同步变换。取消勾选可保留原画布构图和绝对位置；开启时整体会重新居中，左右滑块仍控制角色与文件夹的相对位置。修改后需再次「应用皮肤」才会更新桌面已有图标。单个图标的最大显示区域仍由 Windows 视图决定。

- 左侧「角色左右位置」移动角色；右侧「皮肤位置」页的「文件夹左右位置」移动文件夹。前后片和开口辅助线同步移动，阴影会重新计算。
- 「匹配 Windows 默认文件夹大小」读取本机 Windows 标准文件夹图标的可见轮廓，将文件夹主体等比例缩放到对应范围并居中、底部对齐，同时重置文件夹的位置滑块。纯色文件夹和 PNG 均可用；角色位置保持独立。
- 不同宽高比不能同时匹配宽和高而不变形，因此会在对应轮廓范围内等比例适配、保留留白。匹配后仍可继续微调。
- 「恢复原构图尺寸」恢复原先的文件夹比例和位置。
- 这里匹配的是图标内部的可见比例，不能独立指定某一个桌面图标的屏幕像素大小。最终显示大小由 Windows 桌面/资源管理器的视图和缩放决定；不同尺寸的系统图标绘制也可能略有差异。

默认尺寸读取依据：[Microsoft SHGetStockIconInfo](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shgetstockiconinfo)。

## 系统默认文件夹皮肤

右侧「系统默认」页新增两个按钮：

- **设为系统默认文件夹图标**：将当前预览设为本机普通文件夹的默认图标，无需选择目标文件夹。
- **恢复系统默认图标**：还原首次全局修改前的设置；如果原来已有其他自定义设置，则恢复那些设置。

点击后 Windows 会请求管理员授权，取消则不执行操作。全局设置作用于本机用户，采用 64 位 `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Icons` 的 `3`、`4` 两个图标覆盖值；不会更改系统 DLL、文件关联、缩略图开关或其他注册表值。首次原值和类型会先备份，再写入；重复应用不会覆盖首次备份。操作中断可再次点击恢复，外部修改冲突则停止覆盖。

必要的图标和恢复备份位于 `%ProgramData%\FolderSkinTool`（通常为 `C:\ProgramData\FolderSkinTool`），启用期间请保留。应用过程只保存系统引用所需的 ICO，不自动导出 PNG 或输出目录副本；恢复成功后清理这些 ICO 和备份。单个文件夹的「恢复全部」不撤销系统默认设置，需使用这里的系统恢复按钮。

此方式的效果因 Windows 版本与视图而异，内容缩略图、系统特殊文件夹、已有自定义图标或当前用户单独配置可能覆盖它。不保证所有文件夹、所有视图统一。操作完成后发送刷新通知，不强制重启资源管理器；若仍未显示，请注销后重新登录。
