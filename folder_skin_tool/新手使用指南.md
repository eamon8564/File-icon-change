# 文件夹换肤工具：新手使用指南

这份指南适用于本次制作的 **Folder Skin 文件夹换肤工具**。你不需要会写代码，按按钮操作即可。

它可以把「角色图片 + 文件夹图片」组合成 Windows 图标，也可以导入现成的 ICO，尝试替换系统默认的黄色文件夹图标。生成的是静态图标，不会播放动画。

## 1. 先选你要做的事

| 你想做什么 | 使用哪个功能 | 需要什么素材 |
| --- | --- | --- |
| 只给一个文件夹换皮肤 | 主界面的「应用皮肤」 | 角色 PNG，文件夹皮肤 PNG 可选 |
| 制作图标，先不应用 | 「手动保存 PNG + ICO」 | 同上 |
| 把普通文件夹的系统默认图标换掉 | 右侧「系统默认」→「导入 ICO」 | 已有的 ICO 文件 |
| 撤销单个文件夹换肤 | 「恢复所选文件夹」 | 选择原文件夹 |
| 撤销本工具的所有单独换肤 | 「恢复全部已换肤文件夹」 | 保留换肤记录 |
| 撤销系统默认图标替换 | 「系统默认」→「恢复系统默认图标」 | 保留系统备份 |

**「恢复全部已换肤文件夹」与「恢复系统默认图标」是两种不同的恢复操作。** 如果两种换肤都用过，想完全恢复就需要分别处理。

## 2. 怎样打开工具

1. 打开 `D:\Desktop\interesting\folder_skin_tool`。
2. 双击 **Start.cmd**。
3. 等待工具窗口出现。

当前启动文件使用的是你提供的 Python：

```text
E:\Anaconda\envs\comp5310\python.exe
```

这台电脑的该环境已经检查过，具有界面和图片处理所需的依赖。不要单独移动 `Start.cmd`；它需要和工具的其他文件放在一起。

如果更新了工具，请关闭旧窗口，再双击启动。已经打开的旧窗口不会自动加载新功能。

## 3. PNG 和 ICO 有什么区别

**PNG 是制作素材和查看成品用的图片，ICO 是 Windows 显示图标用的文件。** 把文件名从 `.png` 改成 `.ico` 并不等于转换格式。

制作图标时，可以准备两张图：

- **角色 PNG**：只有角色，背景透明。
- **文件夹皮肤 PNG**：只有空文件夹，背景透明。如果不提供，工具会使用内置的纯色文件夹。

图片可以放在工具的 `assets` 文件夹，也可以从其他位置选择。工具读取原图，不会覆盖原图。

注意，有些网上下载的图片把灰白棋盘格画进了图片里，这不是真透明背景。工具不会自动去白底、去棋盘格或把一张已经合成的「角色 + 文件夹」拆成两个素材。

## 4. 给一个文件夹换皮肤

建议第一次先使用一个自己新建的普通文件夹体验。

1. 在「目标文件夹」旁点击「选择」，选择要换肤的文件夹。
2. 在「角色 PNG」旁选择自己的角色，也可以先用示例小幽灵。
3. 在「文件夹皮肤 PNG（可选）」旁选择空文件夹图片。
4. 如果想用内置文件夹，点击「清除皮肤，使用纯色文件夹」，然后选颜色。
5. 看右侧预览，调整角色和文件夹的位置。
6. 点击 **「应用皮肤」**。
7. 到桌面或文件夹窗口查看；没有马上变化时先按 **F5**。

颜色按钮只影响内置纯色文件夹，不会给你导入的 PNG 重新上色。

### 位置怎么调

| 控件 | 作用 |
| --- | --- |
| 左侧「角色大小」 | 放大或缩小角色 |
| 左侧「角色上下位置」 | 决定角色露出多少 |
| 左侧「角色左右位置」 | 向左或向右移动角色 |
| 右侧「皮肤位置」→「文件夹大小」 | 调整文件夹主体大小 |
| 右侧「皮肤位置」→上下、左右位置 | 移动文件夹，前后片一起移动 |

默认开启去留白时，成品整体会重新居中。因此左右滑块主要改变角色与文件夹之间的相对位置；想保留整个构图在画布中的偏移，可以取消「放大成品，去除四周留白」。

## 5. 让角色看起来坐在文件夹里面

这个效果靠前后遮挡和开口处的阴影实现，排列顺序是：

```text
后面：文件夹后片
中间：角色
前面：文件夹前片，遮住角色下半身
```

使用自定义文件夹 PNG 时：

1. 打开右侧 **「立体遮挡」**。
2. 保持「角色进入文件夹」勾选。
3. 勾选「显示开口辅助线（不导出）」。
4. 调整「开口左端高度」和「开口右端高度」，让虚线贴近文件夹前片的上边缘。滑块越往右，这一端越往下。
5. 用角色位置滑块调整，让头部露出来、身体藏在前片后面。
6. 适当增加「开口阴影强度」。阴影太深时再减小。

辅助线只帮助调整，保存和应用时不会出现在图标里。左右端高度不同，就能形成倾斜的开口。

这不是自动生成三维模型：目前用直线分隔前后片，复杂曲线无法精确自动分割。参考图里的绒面、厚度和立体光照主要取决于素材本身。内置纯色文件夹已经有前后片，不需要调整这两个开口端点。

## 6. 图标太小，应该调哪里

先区分两件事：**图案在图标内部占多大**，以及 **Windows 给整个图标分配多大的显示区域**。

### 图案四周留白太多

保持左侧 **「放大成品，去除四周留白（推荐）」** 勾选。工具会按可见主体收紧边界，忽略外围几乎看不见的残影，让成品接近填满画布。极淡的外围阴影可能被裁掉。

### 去留白后仍想更大

1. 打开右侧 **「成品大小」**。
2. 点击 **「放大到 120%」**，查看预览。
3. 也可以使用滑块，在 100%～160% 之间调整。
4. 如果角色顶部或两侧被裁掉，减小倍率，或点击「恢复完整显示」。

超过 100% 是继续向画布外放大，不会扩大 Windows 分配给这个图标的区域。预览中的裁切也会出现在成品中。

### 「匹配 Windows 默认文件夹大小」有什么用

它读取本机标准文件夹图标的可见轮廓，对文件夹主体作等比例适配，并重置文件夹位置。它不是修改桌面图标大小的按钮，也不能保证不同宽高比的素材看起来完全一样大。整体去留白和成品放大还会进一步影响最终大小。

如果桌面上所有图标都偏小，可在桌面空白处右键，通过「查看」选择更大的图标；这会影响整个桌面，而不是只放大某一个文件夹。

**调整后要再次点击「应用皮肤」。如果用于系统默认换肤，需要先手动保存新的 ICO，再导入并应用它；系统默认功能不会跟随左侧构图自动变化。**

## 7. 什么时候会保存文件

预览和拖动滑块不会自动导出 PNG、ICO。

只有点击 **「手动保存 PNG + ICO」**，选择保存位置和文件名后，才会保存一组同名成品。取消对话框不会保存。工具生成的 ICO 包含 16、32、48、64、128、256 像素六种尺寸。

「应用皮肤」不会在输出目录自动堆积成品，但仍需要在目标文件夹内保存一个隐藏 ICO 和设置文件，供 Windows 长期读取。这是换肤所需文件，不是额外导出副本。

「打开输出目录」打开的是工具的 `generated_icons`。如果你手动保存到了其他目录，成品就在你选择的位置。

## 8. 用现成 ICO 更换系统默认文件夹图标

这项功能独立于左侧构图，不需要选择角色 PNG，也不需要选择目标文件夹。

1. 打开右侧 **「系统默认」**。
2. 点击 **「导入 ICO」**，选择一个有效的 `.ico` 文件。
3. 点击 **「设为系统默认文件夹图标」**。
4. 出现 Windows 管理员权限提示时，允许操作；取消则不执行。
5. 等待工具返回结果。
6. 新建一个普通空文件夹，检查图标是否变化。

工具使用导入的 ICO 原始内容，不重新合成或自动放大。要使用本工具制作的图案，就先手动保存 ICO，再导入。

这是本机范围的默认图标设置，不局限于一个文件夹。但系统特殊文件夹、带内容预览的文件夹、已有单独皮肤的文件夹可能不会跟着变化；不同 Windows 版本和视图也可能表现不同。

### 按了按钮却没变化，怎么办

“设置已写入并校验”只代表系统配置写入成功，不代表桌面已经显示新图标。Windows 可能仍在使用缓存的旧图。

按这个顺序检查：

1. 点击「刷新当前桌面图标」，再按 F5。
2. 用一个新建的普通空文件夹检查，避免已有皮肤和内容预览干扰判断。
3. 如果仍没变化，可在**不注销 Windows** 的情况下重启资源管理器：先完成文件复制、移动等操作，再按 **Ctrl + Shift + Esc** 打开任务管理器，找到 **Windows 资源管理器**，右键选择 **重新启动**。

重启资源管理器时桌面和任务栏会短暂消失，文件夹窗口可能关闭。它不等于注销账号，也不要求重启整台电脑。工具不会自动执行这一步。

如果连资源管理器也不能重启，目前不能保证全局默认图标立即更新。原因可能是正在运行的资源管理器仍使用旧缓存，也可能是当前视图采用了另一种图标来源；反复点击应用不一定有用。可以等允许重启资源管理器时再验证，或者继续使用已支持的单个文件夹换肤功能。

### 本次排查实际确认了什么

此前在这台 Windows 11 24H2 电脑上，已检查到：系统设置正确写入，ICO 可以读取；在新进程中查询新建空文件夹时，Windows 返回的图标路径已经指向导入的 ICO。这说明系统在该查询中识别了设置。

但当时没有替你重启资源管理器，也没有确认桌面最终显示成功。因此，“重启资源管理器”是有依据的下一步，不能写成已经验证成功的结论。

### 之前的 result.json 权限错误

这是管理员进程与普通界面进程之间传递操作结果时出现的问题。代码已改为：普通进程先创建结果文件，管理员进程更新同一个文件；修改系统设置前先检查它能否写入。

遇到旧报错时先关闭旧工具窗口，重新从 `Start.cmd` 打开。若仍报错，保留完整错误信息和恢复备份，不要只凭弹窗判断“系统肯定没有改变”，因为某些失败可能发生在设置写入之后。

## 9. 怎样恢复原样

| 之前做的操作 | 撤销方法 |
| --- | --- |
| 单个文件夹换肤 | 选择该文件夹，点击「恢复所选文件夹」 |
| 多个文件夹分别换肤 | 点击「恢复全部已换肤文件夹」 |
| 系统默认图标替换 | 在「系统默认」页点击「恢复系统默认图标」，处理管理员权限提示 |

恢复的含义是还原换肤前的设置：如果原来已有自定义图标，就恢复那个图标，不一定是黄色文件夹。

如果系统默认皮肤还在启用，撤销单个文件夹的皮肤后，它可能显示系统默认皮肤，这是正常的。想回到最初状态，需要分别撤销两种设置。

恢复后也可能需要刷新或重启资源管理器才能看到变化。若其他软件在换肤之后改动了相关设置，工具会停止覆盖并保留备份，避免丢掉那些新更改。

## 10. 哪些文件需要保留

| 位置 | 用途 | 什么时候可以处理 |
| --- | --- | --- |
| 工具目录的 `data\skin_registry.json` | 记录单个文件夹的换肤前设置 | 所有单独换肤恢复前请保留 |
| 已换肤目标文件夹内的隐藏图标和 `desktop.ini` | Windows 显示该文件夹皮肤所需 | 用恢复按钮处理，不要随意删除 |
| `%ProgramData%\FolderSkinTool` | 系统默认图标及其恢复备份 | 全局恢复完成前请保留；成功恢复会清理本工具相关图标和备份 |
| `generated_icons` 或手动选择的保存目录 | 手动保存的 PNG、ICO 成品 | 由你管理，工具不自动删除 |

`%ProgramData%\FolderSkinTool` 通常是 `C:\ProgramData\FolderSkinTool`。可以把前一个路径粘贴进资源管理器地址栏打开。

单个文件夹换肤记录按路径保存。换肤期间尽量不要移动或重命名目标文件夹；已经移动的，先移回原位置再恢复。

## 11. 常见问题速查

| 问题 | 先检查什么 |
| --- | --- |
| 双击启动失败 | Python 路径是否仍为 `E:\Anaconda\envs\comp5310\python.exe`，启动文件是否还与其他程序文件放在一起 |
| 修改代码后看不到新按钮 | 关闭旧窗口，重新启动工具 |
| PNG 有白底或棋盘格 | 图片可能不是真透明，工具不会自动抠图 |
| 角色完全被挡住 | 向上移动角色，调整开口左右端高度 |
| 图标太小 | 开启去留白，再调整「成品大小」；必要时检查 Windows 的图标视图大小 |
| 角色被裁掉 | 降低成品倍率或角色大小，调整位置 |
| PNG 构图改变了，系统默认图标没变 | 系统默认使用独立导入的 ICO，需要保存新 ICO 后重新导入 |
| 点击系统应用后无变化 | 检查新建空文件夹，刷新；允许时重启资源管理器 |
| 恢复提示没有记录 | 检查选择的路径和恢复按钮是否对应原来的换肤方式 |
| 恢复提示外部修改 | 保留备份，先查清哪个程序修改了设置，不要强行删除配置 |

当前单个文件夹功能面向本地普通文件夹，不支持磁盘根目录、网络共享、目录链接、联接点和云端占位目录。

## 12. 补充说明与参考

单个文件夹换肤通过隐藏 ICO、`desktop.ini` 和文件夹属性实现，不改注册表。系统默认功能则会修改注册表中的默认图标覆盖设置，并先保留恢复备份。两者都不替换 Windows 系统 DLL。

已有自动测试覆盖合成、图标尺寸、应用恢复、外部修改保护，以及系统设置的模拟应用和恢复。测试通过不等于所有 Windows 桌面视图都已验证；最终显示仍需在你的电脑上检查。

- [Microsoft：通过 Desktop.ini 自定义文件夹](https://learn.microsoft.com/en-us/windows/win32/shell/how-to-customize-folders-with-desktop-ini)
- [Microsoft：Shell 图标刷新通知](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shchangenotify)
- [Microsoft 社区：重启资源管理器刷新 Shell 图标的相关方法](https://learn.microsoft.com/en-us/answers/questions/5550181/how-to-restore-missing-arrows-on-desktop-shortcut)

这些参考说明了相关机制或排查方式，不构成对所有 Windows 11 版本全局换肤效果的保证。
